# SpacetimeDB Development Rules

- Before implementing SpacetimeDB code, reference the SpacetimeDB documentation and ensure you are using the proper syntax
- If you aren't certain about the SpacetimeDB implementation, ask the user for clarification
- Commands are executed on macOS (Darwin), so use standard bash syntax with `&&` for chaining commands
- All commands execute from the project root directory (`/Users/hogers/Documents/repos/spacetime-game`), so use relative paths accordingly
